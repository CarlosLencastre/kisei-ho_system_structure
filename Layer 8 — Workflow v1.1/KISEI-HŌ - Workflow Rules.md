## 1. Purpose of the Workflow (v1.1 Updated)

The Workflow ensures that every KISEI-HŌ output follows a predictable, safe, and clinically coherent sequence.
It defines:

- how data is interpreted
- how BTL patterns are identified and integrated
- how Flow States are assessed
- how Kyo/Jitsu balance is determined
- how priorities are established
- how phases are allocated
- how therapies are selected
- how narrative is generated
- how safety is enforced

The Workflow is **mandatory** for all automated and therapist-guided outputs.

---

## 2. Global Workflow Overview (v1.1 Updated)

The KISEI-HŌ workflow follows **8 steps** across **4 stages**:

### Stage 1: Data Entry
1. **Data Acquisition** — Collect raw data from structural, energetic, BTL, Flow State, and Kyo/Jitsu assessment

### Stage 2: Technical Core (PHYSIOCODE)
2. **Data Extraction & Classification** — Classify structural, BTL, energetic, Flow State, and Kyo/Jitsu data
3. **Pattern Integration** — Identify global patterns, BTL pathways, Flow State distribution, Kyo/Jitsu balance
4. **Therapeutic Orientation** — Generate movement qualities, Kyo/Jitsu balancing suggestions

### Stage 3: Clinical Core
5. **Integrated Analysis** — Synthesize all patterns (structural, BTL, Flow States, Kyo/Jitsu)
6. **Therapeutic Plan** — Define therapeutic direction (BTL-aligned, Flow State-appropriate, Kyo/Jitsu balancing)
7. **Exercise Plan** — Build movement framework (BTL-aligned, Kyo/Jitsu-appropriate)
8. **Therapist Session Guide** — Consolidate practical session execution

### Stage 4: Output Core
**Parallel to Stage 3:**
- Safety & Narrative Integration (via Safety & Compliance v1.1 and Translation Rules v1.1)
- Output Generation (via Output Generator v1.1)

Each step has strict rules to ensure consistency across all systems.

## 3. Step 1 — Data Acquisition (v1.1 Updated)

Data is collected from:
- structural evaluation
- energetic evaluation
- axis behaviour
- compensatory patterns
- clinical history (clinical terms **PERMITTED**)
- therapist observations
- **Body Tension Line (BTL) findings** — identify physical tension pathways
- **Energetic Flow State assessments** — assess energy quality and movement
- **Kyo/Jitsu assessment data** — identify deficiency or excess patterns

**Rules:**
- Missing data must not be speculated.
- All data must be classified using official tables.
- Energetic symbols must follow the Energetic Framework v1.1.
- Structural deviations must follow amplitude and direction rules.
- BTL findings must identify pathway type and tension level.
- Flow States must be classified using the five-state system.
- Kyo/Jitsu patterns must identify pattern type and severity.

## 4. Step 2 — Data Extraction & Classification (v1.1 Updated)

Using Structural & Energetic Tables v1.1:

### BTL Classification (v1.1 NEW)

- Map Flow State distribution across the body
- Correlate with BTL pathways

### Kyo/Jitsu Classification (v1.1 NEW)
- Identify Kyo (deficiency) regions
- Identify Jitsu (excess) regions
- Determine dominant pattern (Kyo-dominant, Jitsu-dominant, Mixed)
- Assess pattern severity (Mild, Moderate, Marked)

**Rules:**
- No interpretation occurs at this stage.
- All classifications must use official tables.
- BTL, Flow State, and Kyo/Jitsu data must be complete.

### Flow State Patterns (v1.1 NEW)

### Kyo/Jitsu Patterns (v1.1 NEW)
- Kyo regions and severity
- Jitsu regions and severity
- Kyo/Jitsu balance type
- Therapeutic priority based on balance

### Combined Pattern Synthesis (v1.1 NEW)
Synthesize all pattern types:
- BTL + Flow State correlation
- BTL + Kyo/Jitsu correlation
- Flow State + Kyo/Jitsu correlation
- Global pattern identification

**Rules:**
- Axis behaviour must be evaluated Root → Centre → Firmament.
- Energetic data takes priority in conflicts.
- Compensatory logic must be described.
- Mixed patterns must be documented.
- EFS (Energetic Flow Score) must be calculated with Flow State and Kyo/Jitsu influence.
- No speculation is allowed.

**Outputs:**
- global tendencies
- dominant patterns
- BTL involvement and tension
- Flow State distribution
- Kyo/Jitsu balance
- compensatory chains
- structural-energetic fusion
- safety flags

## 6. Step 4 — Therapeutic Orientation (v1.1 Updated)

Generate non-prescriptive therapeutic guidance:

### Movement Qualities
Based on Pattern Integration:
- Structural-based: grounding, centring, softening, stabilising, lengthening, breathing-based
- BTL-aligned: along specific BTL pathways (Anterior, Posterior, Lateral, Spiral)
- Flow State-aligned: slow rhythmic, softening, allowing, nurturing
- Kyo/Jitsu balancing: soften Jitsu areas first, support Kyo areas gently

### Kyo/Jitsu Balancing Principles (v1.1 NEW)
- Jitsu (excess) → softening, releasing, allowing
- Kyo (deficiency) → gentle support, gradual activation, nurturing
- Mixed patterns → prioritize based on severity and acute vs. chronic

**Rules:**
- Movement qualities must align with BTL, Flow State, and Kyo/Jitsu patterns.
- Sōtai principles: natural movement toward comfort.
- All orientation must be conditional and non-prescriptive.

## 11. Priority Definition (v1.1 Updated)

Priorities determine therapeutic sequence.

### Priority Rules
1. **Safety First**
   - cervical excess (Jitsu in upper body)
   - thoracic rigidity (Stagnant Flow)
   - severe pelvic torsion
   - respiratory restriction
   - energetic collapse (Global Kyo)
   - Rebellious Flow in upper body

2. **BTL/Kyo-Jitsu Balance Second**
   - Primary BTL release
   - Jitsu areas softening
   - Kyo areas gentle support

3. **Flow State Integration Third**
   - Stagnant → Smooth
   - Rebellious → Smooth
   - Excess → Smooth
   - Deficient → gradual activation

4. **Axis Stability Fourth**
   - Root grounding
   - Centre pressure
   - Firmament projection

5. **Structural Refinement Last**
   - segment alignment
   - amplitude reduction

Priorities must be listed explicitly in the plan.

### EFS Integration (v1.1)
EFS includes Flow State and Kyo/Jitsu influence:
- Smooth Flow: +0 to +1
- Stagnant Flow: +1 to +2
- Rebellious Flow: +2 to +3
- Deficient Flow: −1 to −2
- Excess Flow: +2 to +3
- Kyo-dominant: −1 to −3
- Jitsu-dominant: +1 to +3
- Mixed patterns: +1 to +2

### Session Options
- Minimum = 80% (for Jitsu-dominant, focused softening)
- Adequate = 100%
- Conservative = 120% (for Kyo-dominant, gentle approach)

### Phase Allocation
Three phases must always be present:

#### Phase 1 — Intervention & Stabilisation
- Release primary BTL tension
- Soften Jitsu areas
- Support Flow States
- Grounding support for Kyo areas

#### Phase 2 — Active Correction & Integration
- Balance BTL across pathways
- Support Kyo areas progressively
- Integrate Flow States
- Diagonal integration

#### Phase 3 — Consolidation & Reinforcement
- Maintain BTL balance
- Support smooth Flow States
- Maintain Kyo/Jitsu balance
- Long-term coherence

## 13. Safety & Narrative Integration (v1.1 Updated)

### Safety Rules
Safety flags must be applied when:
- energetic excess (Jitsu) affects cervical region
- energetic deficiency (Kyo) affects grounding
- Flow State shows Rebellious Flow in upper body
- Flow State shows Excess Flow with marked BTL tension
- Flow State shows Deficient Flow with global Kyo
- thoracic rigidity affects breathing with Stagnant Flow
- diagonal blockage affects mobility with Spiral BTL
- structural deviations exceed marked amplitude with Jitsu pattern
- **clinical terms from anamnesis are present** (must be transformed via Translation Rules)

Safety overrides all other priorities.

### Narrative Rules
Narrative must:
- follow official tone (Narrative & Persona Guidelines v1.1)
- avoid speculation
- avoid emotional language
- **describe BTL accessibly** (not technical BTL jargon)
- **describe Flow States in narrative form** (not Flow State terminology)
- **describe Kyo/Jitsu without clinical terminology** (not "Jitsu pattern," use "more active/less active")
- describe patterns objectively
- follow the Integrated Analysis structure

Narrative must include:
1. Axis behaviour
2. Structural deviations
3. BTL involvement
4. Energetic states with Flow States
5. Kyo/Jitsu balance
6. Compensatory logic
7. Global tendencies
8. Functional consequences
