## 4. Pre-Output Safety Scan (v1.1 Updated)

Mandatory validation before generating client-facing outputs.

### 4.1 Forbidden Term Check
Scan all outputs for the following prohibited terms (see Safety & Compliance v1.1):

**Clinical terms (allowed in anamnesis, must be transformed in outputs):**
- "posture," "misalignment," "scoliosis" → transform to "body organisation," "pattern," "tendency"
- "joint dysfunction," "spine curvature" → transform to "reduced movement quality," "structural pattern"
- "disease," "diagnosis," "pathology," "syndrome" → transform to "pattern," "condition"

**Biomechanical terms:**
- "biomechanics," "trauma release," "energy healing"

**Diagnostic terms:**
- "dysfunction," "syndrome," "lesion"

**Prescriptive terms:**
- "you must," "correct this," "fix" → transform to "may explore," "might find," "could support"

**Psychological terms:**
- "stress," "anxiety," "trauma" → transform to "pattern of tension," "holding pattern"

**Correctional terms:**
- "align," "strengthen," "stretch" → transform to "find ease," "support naturally," "gentle movement"

**Note:** Clinical terms from anamnesis **ARE PERMITTED** in the input data but must be **TRANSFORMED** via Translation Rules v1.1 pipeline before appearing in outputs.

**Action:** If any forbidden term is found, revise the output to use compliant language via Translation Rules v1.1.

### 4.2 BTL/Flow State/Kyo-Jitsu Check (v1.1 NEW)
Verify BTL, Flow State, and Kyo/Jitsu descriptions are accessible:

- **BTL:** "Posterior BTL dominant" → "tension along the back"
- **Flow State:** "Excess Flow (◎)" → "energy may feel held or accumulated"
- **Kyo/Jitsu:** "Jitsu pattern" → "may feel fuller or warmer"

**Action:** If technical BTL/Flow State/Kyo-Jitsu terminology is present in client outputs, transform via Translation Rules v1.1.

### 4.3 Tone Check
Verify compliance with Narrative & Persona Guidelines v1.1:
- Tone is calm, grounded, and sensory
- Language is neutral and non-prescriptive
- No urgency, intensity, or emotional coloring
- **Conditional language used** ("may," "might," "could")
- **BTL/Flow State/Kyo-Jitsu described accessibly**

**Action:** If tone is non-compliant, revise the narrative to align with guidelines.

### 4.4 Dependency Check
Ensure all referenced files are up-to-date and aligned:
- Master Document v1.1 (governance, language rules)
- Narrative & Persona Guidelines v1.1 (tone/language, BTL/Flow State/Kyo-Jitsu)
- Energetic Framework v1.1 (energetic logic, Flow States, Kyo/Jitsu)
- Structural & Energetic Tables v1.1 (BTL, Flow States, Kyo/Jitsu classifications)
- Templates v1.1 (output structure, BTL/Flow State/Kyo-Jitsu templates)
- Translation Rules v1.1 (BTL/Flow State/Kyo-Jitsu transformation pipeline)
- Safety & Compliance v1.1 (forbidden terms, narrative safety)

**Action:** If dependencies are outdated, update the file references before generating outputs.

### 4.5 Language Check (v1.1 NEW)
Verify correct language based on anamnesis:
- **Client outputs:** PT-PT or EN (based on anamnesis language preference)
- **Therapist outputs:** PT-PT (full technical detail)

**Action:** If language is incorrect, regenerate with correct language setting.

### 4.6 Workflow Compliance
Confirm the output follows the 8-step pipeline (see Workflow Rules v1.1):
1. Data Acquisition (including BTL, Flow States, Kyo/Jitsu)
2. Data Extraction & Classification
3. Pattern Integration (combined synthesis)
4. Therapeutic Orientation (BTL-aligned, Kyo/Jitsu balancing)
5. Integrated Analysis
6. Therapeutic Plan
7. Exercise Plan
8. Therapist Session Guide

**Action:** If any step is missing, regenerate the output from the beginning.
