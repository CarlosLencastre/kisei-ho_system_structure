## 1. Purpose of the Clinical Architecture

The Clinical Architecture defines **how the system thinks**.

It ensures that:
- data is interpreted consistently
- patterns are recognised correctly
- **Body Tension Lines (BTL) are identified and integrated**
- **Energetic Flow States are assessed and mapped**
- **Kyo/Jitsu patterns are classified and balanced**
- therapeutic decisions follow official rules
- outputs remain coherent across all contexts
- safety is always prioritised
- narrative follows the correct tone
- language rules are followed (PT-PT therapist, PT-PT/EN client)

The architecture is **modular**, **hierarchical** and **rule‑driven**.

---

## 2. Global Architecture Overview

The PHYSIOCODE system operates through five major layers:

1. **Data Layer** (with BTL, Flow States, Kyo/Jitsu)
2. **Classification Layer** (with BTL classification, Flow State classification, Kyo/Jitsu classification)
3. **Interpretation Layer** (with BTL pattern integration, Flow State integration, Kyo/Jitsu integration)
4. **Therapeutic Logic Layer** (with BTL-aligned therapy, Flow State-aligned therapy, Kyo/Jitsu balancing)
5. **Output Layer** (with BTL narrative, Flow State narrative, Kyo/Jitsu narrative)

Each layer has strict rules and dependencies.

---

## 3. Layer 1 — Data Layer
### (Extraction → Normalisation → Validation)

This layer receives raw clinical data from:
- structural evaluation
- energetic evaluation
- axis behaviour
- compensatory patterns
- clinical history
- therapist notes
- **Body Tension Line (BTL) findings**
- **Energetic Flow State assessments**
- **Kyo/Jitsu assessment data**

**Rules:**
- Missing data must not be speculated.
- All data must be normalised into official formats.
- Structural deviations must use direction + amplitude.
- Energetic states must use official symbols.
- Axis behaviour must follow Root → Centre → Firmament.
- **BTL findings must identify pathway type (Anterior, Posterior, Lateral, Spiral)**
- **Flow States must be classified (Smooth, Stagnant, Rebellious, Deficient, Excess)**
- **Kyo/Jitsu patterns must identify deficiency or excess**

**Anamnesis Rule:** Clinical, biomechanical, diagnostic, and emotional terms are **PERMITTED** in the anamnesis. These are transformed via Translation Rules pipeline before appearing in any output.

**Outputs:**
- validated structural map
- validated energetic map
- validated axis map
- **validated BTL map**
- **validated Flow State map**
- **validated Kyo/Jitsu pattern map**

## 4. Layer 2 — Classification Layer
### (Tables → Symbols → Categories)

This layer classifies all data using official tables:

- Structural & Energetic Tables (with BTL descriptions)
- Energetic Framework (with Flow States, Kyo/Jitsu patterns)
- Axis Behaviour Model
- **Body Tension Line Classification**
- **Energetic Flow State Classification**
- **Kyo/Jitsu Pattern Classification**
- Compensation Categories

**Rules:**
- No interpretation occurs here.
- Classification must be exact and non‑speculative.
- All symbols must follow official notation.
- **BTL classification must identify pathway and tension level**
- **Flow State classification must use the five-state system**
- **Kyo/Jitsu classification must identify pattern type and severity**

**BTL Classification System:**
| Category | Description |
|----------|-------------|
| Anterior BTL | Jaw → Chest → Hip flexors pathway |
| Posterior BTL | Skull → Spine → Heels pathway |
| Lateral BTL | Ear → Side body → Foot pathway |
| Spiral BTL | Diagonal crossing pattern |

**Flow State Classification System:**
| State | Symbol | Description |
|-------|--------|-------------|
| Smooth Flow | → | Unobstructed movement |
| Stagnant Flow | ⨂ | Partial or complete obstruction |
| Rebellious Flow | ⨂ (reversed) | Counter-flow movement |
| Deficient Flow | ⊖ | Insufficient movement |
| Excess Flow | ◎ | Congested movement |

**Kyo/Jitsu Classification System:**
| Pattern | Symbol | Description |
|---------|--------|-------------|
| Kyo (虚) — Deficiency | ⊖ | Empty, weak, insufficient function |
| Jitsu (実) — Excess | ◎ | Full, tense, congested function |

**Outputs:**
- classified structural deviations
- classified energetic states
- classified axis behaviour
- **classified BTL findings**
- **classified Flow States**
- **classified Kyo/Jitsu patterns**
